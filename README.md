Книга відгуків (Лабораторна робота 1)

Простий веб-додаток на Maven + Jetty 11 + H2. На сторінці є форма, де можна написати своє ім'я і відгук, а нижче показується список усіх відгуків. Відгуки зберігаються в базі даних H2.

Версії:
JDK 21
Maven 3.8.4
Jetty 11.0.24
H2 2.2.224

Як запустити:
mvn clean compile
mvn jetty:run
Після запуску відкрити в браузері http://localhost:8080/
Зупинити сервер: Ctrl+C

База даних:
URL: jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE
Користувач: sa, пароль порожній
Файл бази: data/guest.mv.db (створюється сам у папці проєкту при першому запуску)
Таблиця comments теж створюється автоматично при старті додатку.

Ендпоїнти:
GET / - сторінка з формою і списком відгуків
GET /comments - повертає всі відгуки у форматі JSON (нові зверху)
POST /comments - додає новий відгук (поля author і text)

Відповіді сервера:
204 - відгук успішно додано
400 - помилка валідації (порожнє поле, ім'я довше 64 символів або текст довший 1000)
500 - помилка бази даних

Після додавання відгуку в консолі з'являється запис у лог, наприклад:
INFO New comment: id=1, author='Сергій', length=12
